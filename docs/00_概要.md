# Project Eclipsion 概要

## プロジェクト概要

Project Eclipsion は、
C#製のコンソールベース 2D リアルタイムシューティングゲームです。

ローグライト・ハクスラ・ビルド構築を主軸とし、
将来的には MonoGame や独自エンジンへの移行を想定しています。

---

## 現在の開発フェーズ

Phase1:
Console MVP

現在の目的:
- ゲームループ構築
- プレイヤー
- 敵
- 弾
- 武器
- 当たり判定
- Console描画

を最小構成で完成させること。

---

## 最重要設計

ゲームロジックと描画を分離する。

Game Logic
↓
Renderer

この構造を維持する。

---

## 現在採用している設計

- クラスベース設計
- レイヤー分離
- 小規模責務
- テスト可能設計
- Console First

---

## 現在採用していないもの

以下は将来的に検討する。

- ECS
- MonoGame
- SQLite
- Dedicated Server
- マルチプレイ
- Mod対応

---

## ECS方針

Phase1:
導入しない

Phase2:
必要性を監視する

Phase3:
以下の問題が出た場合に導入検討

- GameState肥大化
- Update複雑化
- 敵・弾大量化
- 状態異常組み合わせ増加
- パフォーマンス問題
